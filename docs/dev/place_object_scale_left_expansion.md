# `place_object_scale_left` 扩展实验方法

## 用途

“分组逐步扩展”适合作为后续调试任务的参考手段：先用保守范围确认任务流程，再逐步扩大场景随机化范围，并用成功率和失败 seed 连续长度判断扩展是否越过可靠工作空间。

该方法用于定位“多样性增加”和“规划成功率下降”之间的边界，不等于必须长期保留分级采样逻辑。

## 实验方法

对 `place_object_scale_left`，实验阶段使用成功 episode 数作为切换计数，而不是使用原始 seed 数：

| 成功 episode | 采样范围 | yaw |
| --- | --- | --- |
| 0–166 | 基础范围 | ±15° |
| 167–333 | 一级扩展 | ±15° |
| 334–499 | 二级扩展 | ±30° |

失败 seed 不推进计数，因此不会因为失败而提前进入更困难的范围。实验中不使用安全锚点比例；否则最终数据会混入固定比例的原始方法，难以判断扩展本身的效果。

每一阶段应记录：

- 成功数量和尝试数量；
- 总体成功率与阶段成功率；
- 最大连续失败长度；
- EMIX 交点在早期、中期、末端的分布；
- 位置和 yaw 随机化是否真正传递到 EEF 轨迹。

## 本任务的实验结论

本次 500 条实验数据的统计为：

| 阶段 | 成功 | 尝试 | 成功率 |
| --- | ---: | ---: | ---: |
| 基础 | 167 | 177 | 94.35% |
| 一级扩展 | 167 | 188 | 88.83% |
| 二级扩展 | 166 | 212 | 78.30% |
| 总体 | 500 | 577 | 86.66% |

最大连续失败长度为 2，没有出现连续 100 个 seed 失败。

## 当前标准实现

实验表明二级扩展能提供当前任务所需的更大随机化范围，因此当前标准实现不再进行分级：从第一个 seed 到整个 episode budget 都使用二级扩展参数。

标准几何和采样参数为：左臂根部位于 x=-0.30 m，右臂根部位于
x=+0.30 m，头部相机保持场景中央位置。object 和 scale 使用同一
左移后的重叠范围：

```text
object x: [-0.42, -0.08]
object y: [-0.18,  0.08]
scale  x: [-0.42, -0.08]
scale  y: [-0.18,  0.08]
object yaw: ±30°
```

唯一标准配置为：

```text
third_party/RoboTwin/task_config/place_object_scale_left.yml
```

任务实现直接使用上述范围，不根据 `ep_num` 切换工作空间，也不使用安全比例、pilot 配置或 waypoint。

本次几何布局变化会同时改变图像中的机械臂遮挡关系和 expert 的动作分布，旧的居中布局数据、EMIX index 以及旧 checkpoint 不应与新数据混用。重新采集后应使用新的数据集目录完成 LeRobot 转换和 EMIX index 构建，再重新训练并使用同一新布局配置评估。

## 解释可视化结果时的注意事项

该任务的目标是把物体放到固定 scale 功能点，成功轨迹天然会在末端收敛。位置和 yaw 随机化主要改变初始抓取状态，不一定产生不同的后续运动拓扑。因此，EMIX 交点仍集中在末端并不自动表示随机化没有生效。

若需要显著增加运动过程中的交点多样性，应进一步改变合法接近方向或目标拓扑；单纯扩大同一工作空间和 yaw 范围的收益存在上限。
